      Tentang data

      Sumber

      • Cloudflare Radar untuk tren serangan DDoS dan lapisan 7 ke Indonesia.
      • abuse.ch (URLhaus, Feodo Tracker, ThreatFox) untuk indikator malware dan server komando botnet.
      • SANS ISC/DShield dan AlienVault OTX untuk IP pemindai dan brute force.
      • AbuseIPDB dan GreyNoise Community untuk skor reputasi.
      • MaxMind GeoLite2 untuk negara dan ASN dari alamat IP.

      Cara membaca

      • Ini sampel dan agregat dari pihak ketiga, bukan seluruh serangan ke Indonesia.
      • Negara asal berasal dari GeoIP. Pelaku sering memakai proxy, VPN, atau server yang sudah dibobol.
      • Satu IP bisa saja perangkat korban. Periksa dulu sebelum memblokir permanen.
      • Halaman ini sedang menampilkan data contoh. Alamat IP memakai rentang dokumentasi (RFC 5737), jadi bukan IP sungguhan.
